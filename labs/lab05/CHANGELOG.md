# История изменений лабораторной работы № 5

## [5.0.0] — 2026-08-31

### Добавлено

- Классическая сеть Петри для 3–8 обедающих философов и модификация с
  позицией-арбитром.
- Прямой алгоритм Гиллеспи, непрерывная mass-action аппроксимация и проверка
  разрешённых переходов.
- Базовый эксперимент для пяти философов, семь графиков и анимация маркировки.
- Параметрический эксперимент из 960 траекторий для четырёх интенсивностей
  захвата левой вилки.
- Два выполненных блокнота Jupyter и две страницы документации Quarto,
  полученные из литературного Julia-кода.
- Отчёт в QMD, DOCX и PDF, самодостаточная HTML-презентация и редактируемый
  PPTX из 24 слайдов.
- 23 автоматические проверки структуры, динамики, ODE и индекса Джейна.

Модель, выполненные блокноты и результаты расчётов:
[0a2efb9](https://github.com/dakuokkonen1/study-2026-simulation-modeling/commit/0a2efb99d40cdeb5cbda798e50f8361bdcc695af).

### Проверено

- Классическая базовая траектория достигла deadlock после пяти событий.
- Сеть с арбитром выполнила 31 цикл питания без глобальной блокировки.
- В 960 прогонах наблюдаемая доля deadlock составила 1,0 для классической
  сети и 0,0 для сети с арбитром на горизонте 50.
