# Changelog

## [3.0.1] - 2026-08-31

### Исправлено

- Содержание приведено к главе 3 практикума: вместо СМО M/M/1 реализована
  агентная модель Daisyworld на периодической решётке 30×30.
- Контрольные состояния подписаны шагами 0, 5 и 45; выбор свободной клетки
  использует генератор случайных чисел модели.

### Добавлено

- Семь самостоятельных сценариев: состояния, анимация, численности,
  переменная светимость и три параметрические серии.
- Для max_age = 25/40 и доли белых 0,2/0,8 выполнены все четыре сочетания.
  Сохранены 25 графиков, анимация и полные CSV-ряды.
- Семь выполненных блокнотов; 19 проверок начального состояния,
  динамики, повторяемости и графика светимости.

### Изменено

- Отчёт DOCX/PDF заменён исследованием Daisyworld с листингами всех сценариев.
- Презентация HTML и PPTX содержит 17 слайдов с базовыми и параметрическими
  результатами. В сценарии ramp чёрный вид исчезает на шаге 310.

## [3.0.0] - 2026-08-30

### Added

- Добавлена дискретно-событийная модель одноканальной СМО M/M/1.
- Имитационные оценки $\rho$, $L$, $L_q$, $W$ и $W_q$ сопоставлены со стационарными формулами.
- Выполнен нагрузочный эксперимент для семи значений интенсивности входного потока.
- Добавлены CSV-таблицы, пять графиков и выполненные блокноты Jupyter.
- Добавлены 11 автоматических тестов, отчёт QMD/DOCX/PDF и HTML-презентация.
- Добавлена редактируемая PPTX-презентация.

### Changed

- В отчёт включены полные листинги модели, экспериментов, генератора форматов и тестов.
- Отчёт оформлен на A4 по образцу второй работы; добавлены команды воспроизведения.

### Fixed

- В презентации исправлено значение средней очереди для серии прогонов при загрузке 0,9091.
- Увеличен левый отступ графиков: подписи осей больше не обрезаются.
- HTML-страницы экспериментов собираются из выполненных блокнотов без повторного запуска ядра Julia.
