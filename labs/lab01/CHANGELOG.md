# Changelog

История изменений лабораторной работы № 1 «Экспоненциальный рост».

## [1.2.0] — 2026-08-29

### Анализ результатов

- Сопоставлены численное решение уравнения $du/dt=\alpha u$ и точное
  решение $u(t)=u_0e^{\alpha t}$ на одной временной сетке.
- Для $u_0=1$, $\alpha=0{,}3$ и $t=10$ получено численное значение
  20,085449 при точном 20,085537; относительная ошибка составляет
  $4{,}40\cdot10^{-6}$.
- Рассчитано время удвоения $T_2=\ln 2/\alpha$: для базового опыта
  оно равно 2,310491. Показано, что увеличение скорости роста сокращает
  время удвоения обратно пропорционально $\alpha$.
- По пяти параметрическим опытам сопоставлены траектории и конечные значения:
  при изменении $\alpha$ от 0,1 до 1,0 численная оценка $u(10)$ возрастает
  от 2,718282 до 22021,015566.
- В таблицах сохранены как параметры опыта, так и его результаты:
  временной ряд, конечное значение, время удвоения и погрешность базового решения.

## [1.1.0] — 2026-08-29

### Анализ модели

- Разобрана зависимость скорости изменения величины от её текущего значения.
- Получено аналитическое решение задачи Коши и объяснён смысл параметров
  $u_0$ и $\alpha$.
- Выведена формула времени удвоения и сопоставлена с результатами
  параметрического исследования.

## [1.0.0] — 2026-08-29

### Добавлено

- Модуль `src/exponential_growth.jl`: правая часть уравнения,
  аналитическое решение и вычисление времени удвоения.
- Базовый сценарий `01_exponential_growth.jl`: начальное значение 1,
  скорость роста 0,3, интервал наблюдения от 0 до 10 и шаг сохранения 0,1.
- Численное интегрирование методом Tsit5, вычисление абсолютной ошибки
  в каждой сохранённой точке и относительной ошибки в конце интервала.
- Параметрический сценарий `02_exponential_growth.jl` для
  $\alpha\in\{0{,}1;0{,}3;0{,}5;0{,}8;1{,}0\}$ при одинаковых начальных
  условиях и горизонте наблюдения.
- Сохранение результатов отдельных опытов и повторное использование
  уже рассчитанных наборов параметров.
- Измерение времени численного решения для каждого значения скорости роста;
  результаты отделены от характеристик самой динамической модели.

### Проверки модели

- Сравнение конечного численного значения с аналитическим решением
  с относительным допуском $10^{-5}$.
- Проверка формулы времени удвоения для положительной скорости роста.
- Отклонение нулевой скорости при запросе конечного времени удвоения.
