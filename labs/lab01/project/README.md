# Проект первой лабораторной работы

Воспроизводимый DrWatson-проект для численного исследования уравнения

\[
\frac{du}{dt}=\alpha u, \qquad u(0)=u_0.
\]

## Что реализовано

- одиночный численный эксперимент и сравнение с аналитическим решением;
- параметрическое исследование для пяти значений `α`;
- сохранение таблиц, данных и графиков;
- генерация из литературного Julia-кода чистых скриптов, Jupyter-ноутбуков и
  Quarto-документации;
- выполнение обоих ноутбуков и автоматические тесты.

## Воспроизведение

Все зависимости запускаются изолированно и не меняют Julia, Python, Git или SSH
на основной системе.

```bash
docker compose build
docker compose run --rm lab01 make setup
docker compose run --rm lab01 make all
```

После первого запуска кэш Julia хранится только в локальном каталоге `.julia/`,
который исключён из Git и удаляется вместе с папкой проекта.

## Результаты

- `data/` — таблицы CSV и кэш вычислений JLD2;
- `plots/` — графики PNG;
- `scripts/01_exponential_growth/` и `scripts/02_exponential_growth/` — чистый код;
- `notebooks/` — выполненные Jupyter-ноутбуки;
- `markdown/` — документы Quarto и HTML.
