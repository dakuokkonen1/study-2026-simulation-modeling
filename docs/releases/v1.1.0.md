# v1.1.0 — Отчёт, презентация и записи лабораторной работы № 1

Релиз дополняет воспроизводимую реализацию лабораторной работы оформленными
материалами для сдачи и повторения. Документы подготовлены для Куокконен
Дарины Андреевны, группа НФИбд-01-23, с сохранением академических реквизитов
РУДН имени Патриса Лумумбы.

## Документы

- отчёт на 22 страницах: HTML, DOCX и PDF;
- презентация из 11 слайдов: HTML, PPTX и PDF;
- 25 снимков терминала и Jupyter, а также пять графиков включены в отчёт;
- все слайды проверены на переполнение, PDF-экспорт проверен визуально.

## Видеозаписи

- полное выполнение лабораторной работы в терминале и Jupyter;
- сборка отчёта с частичным редактированием исходника и просмотром PDF;
- сборка презентации с частичным редактированием QMD/JS и просмотром слайдов.

Две новые записи имеют разрешение 1920×1080, частоту 30 кадров/с и длительность
более 15 минут каждая. В кадре нет указателя мыши; команды и текст вводятся
посимвольно с естественными паузами.

## Воспроизведение

```bash
cd labs/lab01/report
make all

cd ../presentation
make all
```

Сценарии генерации документов и записей входят в исходный архив релиза.
