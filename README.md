# Имитационное моделирование

Учебный репозиторий для восьми лабораторных работ по курсу «Имитационное моделирование».

## Автор

`dakuokkonen`

## Структура

| Работа | Тема | Состояние |
|---|---|---|
| `lab01` | Подготовка стенда и модель экспоненциального роста | выполнена |
| `lab02`–`lab08` | Последующие лабораторные работы | подготовлены каталоги |

Каждая работа находится в отдельном каталоге `labs/labNN`. Исходный код первой
работы, инструкции запуска и воспроизводимое Docker-окружение находятся в
[`labs/lab01/project`](labs/lab01/project).

## Быстрый запуск первой работы

```bash
cd labs/lab01/project
docker compose build
docker compose run --rm lab01 make setup
docker compose run --rm lab01 make all
```

Результаты сохраняются в `data/`, `plots/`, `notebooks/` и `markdown/` внутри
проекта первой лабораторной работы.
